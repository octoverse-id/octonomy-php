# Roadmap

The 1.x line has none. It carries the `/api/v2` surface its `1.0.0` ships, which is every resource
group (vocabularies, tags, tag aliases, tag resolution, tag assignments, resource tags, audit logs)
and the health probes, and after `1.0.0` it takes security fixes and major bug fixes only
([#33](https://github.com/octoverse-id/octonomy-php/issues/33)). New endpoints, and support for API
changes a later server release makes, ship on 2.x: `main`'s
[`docs/roadmap.md`](https://github.com/octoverse-id/octonomy-php/blob/main/docs/roadmap.md) has the
recipe for adding one.
